Cells:
  Underpopulation: A live cell with fewer than two live neighbors dies.

  Stasis: A live cell with two or three live neighbors lives on to the next generation.

  Overpopulation: A live cell with more than three live neighbors dies.

  Reproduction: A dead cell with exactly three live neighbors becomes a live cell.


Toriodal Grid:
  -new_row = (row + offset + totalRow) mod totalRows
  -new_column = (column + offset + totalColumns) mod totalColumns


Law #1: If a cell is alive, it dies when it has fewer than 2 or more than 3 live neighbors, else it stays alive.

Law #2: If a cell is dead, it can come alive only if it has exactly 3 live neighbors, else it stays dead.
